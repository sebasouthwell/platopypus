Shared credentials

Logins and keys an agent handed to you with credshare: generated passwords, test accounts, admin logins. Separate from the Vault, which holds the tokens agents use. Kept 7 days; tap a card to copy fields or open the service.

Security

This app is root-level control of the box. Keep two-step codes on and sign out of devices you no longer use. Lost your authenticator? Run box.ps1 reset-totp from the laptop.

AI agents

Sign in opens a shell running the agent's login; follow the link it prints and paste the code back. Claude profiles are separate config folders, so each can be signed in to a different account.
