# Security level: throwaway

A one-time, disposable project. Speed is the only goal.

- Build the simplest thing that works, as fast as possible. No security review, no tests unless asked.
- Hard-coded test data is fine. Do not spend time on auth, validation or hardening.
- Still never put real credentials, personal data or the user's own logins into it, and never publish it as a public
  repo without asking. Assume it will be deleted soon.
